# Shopping Cart Project

Welcome to the **Shopping Cart Project**! This is a simple yet effective e-commerce web application where users can browse products, add them to their cart, and manage purchases. Built with **HTML, CSS, and JavaScript**, this project provides a seamless shopping experience.

## 🚀 Features

- **🛍️ Product Categories** – Browse products by categories: Mobiles, Laptops, Accessories, Food, Electronics.
- **➕ Add to Cart** – Easily add products to your cart and manage quantities.
- **🛒 Cart Management** – Update quantities, remove items, and view total cost dynamically.
- **📱 Responsive Design** – Works smoothly on both **desktop** and **mobile** devices.
- **💳 Checkout Process** – Simulated checkout process for a complete shopping experience.

## 🛠️ Installation

To run this project locally, follow these steps:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/DharaniSriHamsa/shopping-cart.git
```

### 2️⃣ Navigate to the Project Folder
```bash
cd shopping-cart
```

### 3️⃣ Open the Project
Simply open **index.html** in your browser.

## 🎯 How to Use

### 🏷️ Browse Products
- Use the category menu to filter products (Mobiles, Laptops, Accessories, Food, Electronics).

### 🛍️ Add to Cart
- Click the **"Add to Cart"** button on any product.

### 🛒 Manage Cart
- Click the **cart icon** to view items.
- Update quantities or remove items as needed.

### 💳 Checkout
- Click **"Checkout"** to complete your purchase (simulated).
